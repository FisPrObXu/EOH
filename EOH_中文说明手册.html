EOH — Eyes of heaven

中文说明手册 · 版本 0.4.1
BSE 图片颗粒审核、空间距离零假设检验与粒径统计。软件界面和新生成报告使用英文；本手册解释对应按钮及操作。

完整解压分发包后，进入 EOH 文件夹，双击 EOH.exe。程序运行组件位于同目录的 _internal 文件夹。可将软件解压到可写路径，例如 E:\EOH。

1．已有案例如何继续使用

在主窗口 Output case folder（输出案例目录）旁点击 Browse，选择原来的“分析结果”文件夹。案例列表会读取其中的图片、审核版次和最新结果。路径、图片名称、人工填写的备注保持原样。以前生成的中文报告保留；重新生成的报告使用英文。

本项目源码版也可运行项目根目录的 analyse_tool.cmd。便携版首次运行会在 EXE 旁建立“工作数据”，保存应用设置、日志及缓存；输入图片和输出案例目录由您选择。

2．新图完整流程

  1. 选路径。Input image folder 选择输入图片目录，Output case folder 选择输出目录。便携版可选择其他盘符；本项目源码版继续遵守 E 盘工作文件要求。
  2. 导入。点击 1. Import image；批量导入用 Batch import。同一输出目录内已导入的原图会保留已有案例，避免重复覆盖。
  3. 裁切与定标。在 1. Crop 模式拖框，去掉仪器文字栏／比例尺栏；切换 2. Draw scale bar 沿原图比例尺画线，填写真实长度，再点击 Calibrate from drawn bar。也可直接填写可靠的 Native pixel size（μm/pixel）。物理像素尺寸由图像比例尺或已知标定值提供。
  4. 设定参数。在看结果前确定距离上限、步长、近距离阈值和粒径安全边界。默认粒径保护 1 μm；距离保护跟随距离上限，通常 5 μm。选 Distance tests + grain sizes 或 Grain sizes only。
  5. 建立候选。点击 Create candidate outlines，然后 2. Open review 打开本机浏览器审核页。
  6. 审核并保存。核对安全窗口、排除区、明暗类别与边界，点击 Save all changes，确认状态为 Saved to project folder · Revision …。
  7. 出报告。回到主窗口，勾选人工审核确认，点击 3. Generate report。结果按审核版次保存，旧结果保留。完成新的修改后重新生成报告即可更新图件。

通过 EOH 的 Open review 打开本机审核页，保存操作会写入对应案例。若提示保存冲突，保留当前页面，先解决冲突或用主窗口 Restore review backup 恢复完整备份。

4．孔洞、裂隙和不满意的排除区

  1. Hole: place point：设置 Exclusion radius，在孔洞中心点一下；默认半径 1 μm，红色圆盘排除统计。
  2. Crack: draw line：沿裂隙画开放线；默认半径 0.5 μm，为线两侧和端点增加同半径缓冲。总宽度约为两倍半径。
  3. 在 Existing exclusions 选中已有区域，Change selected radius 改半径，或 Delete selected exclusion 删除。不满意的初始排除区也可在此选择删除。
  4. 保存后红色排除区和橙色 W 更新；Safe window 可在 Distance tests 和 Grain sizes 之间切换。两种窗口的保护距离可不同。

粒径统计只纳入整个颗粒都在粒径窗口内的对象；跨界整粒排除。修改边框会改变像素面积、等效圆直径和纳入状态。距离统计按中心纳入，因此与粒径统计的粒数可以不同。

5．小亮颗粒识别

导入时默认启用局部对比度增强；Balanced 为均衡，Sensitive 包含较弱小亮点，Conservative 减少杂点。Standard / Tighter / Wider boundary 控制边界范围。最低原生像素数默认 2。主窗口增强按钮会另存新案例并保留已保存手工修改；新候选仍需审核。

6．调整出图参数

选择案例，点击 Plot settings。三个页签：

页签主要设置
Distributions and curvesBinning：自动／组数／组宽；Bar width fraction：柱宽比例；Overlay a smooth distribution curve：密度曲线；Curve display：阶梯、折线、平滑；Random curves：展示曲线数量。
Canvas and legend画布宽高、坐标字号、留白、网格、图例位置、字号、字体、列数及边框。0 表示模板；字号自定义下限为 5 pt。
Plotted objects各类对象显隐、图例文字、颜色、线型和线宽。隐藏只影响图面，完整数据仍保留。

点击 Save plot settings 后重新生成／重绘报告。柱宽比例 1 表示相接，0.8 留 20% 间隙；组宽越大通常柱越粗、组数越少。折线与平滑按已有测量点调整显示，检验采用保存的统计结果。Random curves 为 1–4999，4999 展示全部；布局图只展示第 1 组，正式检验仍使用全部 4999 次模拟。

如希望采用参考图的简洁风格，点击 Apply reference style：曲线使用折线连接，隐藏网格线，图例放在下方两列，并恢复比较曲线的默认配色。按钮保留现有的粒径分组、随机曲线数量、对象显示开关和自定义图例文字；设置完成后仍可逐项调整。点击 Save plot settings 保存，或在汇总设置中点击 Save and redraw latest summary 保存并重绘。案例设置与汇总设置分别保存，均需分别调整。

7．批量汇总与图形编辑

在案例名称前打勾，点击 Export batch summary。汇总包括所选案例的空间分析与粒径两份报告、合并统计表和独立图件。Summary plot settings 控制汇总图；独立报告采用各自保存的 Plot settings。Redraw latest summary 使用已冻结分析数据更新显示。

独立样品与置信区间：勾选案例后点击 Set sample IDs for selected cases。来自同一独立样品的不同视野填写相同 ID，不同的独立样品填写不同 ID；留空表示身份未知。汇总报告会输出样品与图片对应表、逐样品粒径和空间统计表、逐样品粒径图。完整填写且至少有两个独立样品时，汇总粒径曲线可显示按样品重抽样的 95% 逐点置信区间。区间表示逐粒径的样品重抽样范围；独立性、代表性与视野覆盖情况由实验记录确认。已记录的图像重叠对应探索性范围，并在图和报告中标示。

颗粒数与面积：粒径累计图分别按颗粒数量和二维截面面积加权，按相内已纳入颗粒分别累计；面积加权描述二维截面面积的累计比例。表格 grain_size_weighted_quantiles.csv 给出两种权重的 D10、D50 和 D90，另存逐点区间源数据。

高密度等面积随机布局：整组拒绝法效率不足时，程序改用保持原约束的随机移动近似采样。报告标记 approximate，并保存采样诊断；近似等面积结果用于描述性对照，报告提供采样诊断。中心位置模型的正式检验保持原方法。

图件分别提供 PDF、SVG、600 dpi PNG/TIFF；可继续在矢量软件中编辑 PDF／SVG。tables 保存逐粒距离、面积、粒径、累计曲线及模拟结果；inputs 保存参数与来源，reviewed 保存原生标签，code 保存对应源码。备份时复制完整案例文件夹。

8．随机曲线和零假设怎样理解

Observed 是实测；Evenly spread 尽量均匀铺开，只作直观参照；First random example 展示第 1 次随机结果；浅蓝线表示多次随机布局。Baseline 是指定随机模型的正常水平；Upper MC 是同模型的 95% 模拟参考上界。

中心模型固定暗区与 W，随机放置同样数量的亮点中心；等面积模型还保留总面积，将面积均分为指定数量，满足单块 ≤ 原最大亮区 75% 的上限，整块位于 W 内、暗区外且不重叠。均匀铺开和随机布局分别提供直观空间参照与随机模型对照。曲线更早上升表示更多点在近距离内，但正式结论还需结合完整曲线、效应大小和匹配的随机检验。

粒径采用二维等效圆直径 d = √(4A/π)；物相名称由用户提供。报告分别列出颗粒数量、模拟次数与样品数量。

9．GPU、小屏幕和错误日志

Compute device 可选 Auto (prefer GPU)、CPU only 或 Prefer GPU (CPU fallback)。支持的均匀与等面积布局步骤使用 NVIDIA CUDA GPU，高密度随机移动及报告绘制使用 CPU。批量任务复用 GPU，首次运行时初始化计算环境。

主窗口和参数页支持上下、左右滚动，Shift＋滚轮左右移动。窗口按屏幕限高；主要对话框按钮固定在底部。计算时用 Stop calculation 请求停止；完成后可正常关闭窗口。

启动错误在“工作数据/logs/startup_error.txt”，启动过程在 desktop_startup.log。案例错误在对应 logs，compute_backend.json 记录实际设备与回退信息。反馈时附版本、复现步骤和错误日志。
