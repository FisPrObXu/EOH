# EOH 0.4.1 本地使用指南

请从 [v0.4.1 发布页](https://github.com/FisPrObXu/EOH/releases/tag/v0.4.1)下载 Windows ZIP，完整解压后运行 `EOH/EOH.exe`；请保留 `_internal` 文件夹。完整中文操作步骤见[中文说明手册](../EOH_%E4%B8%AD%E6%96%87%E8%AF%B4%E6%98%8E%E6%89%8B%E5%86%8C.html)。

已有分析案例可在主窗口 **Output case folder → Browse** 选择原案例所在文件夹。原始显微图片、审核记录与分析结果不包含在公开仓库中。使用自己的图片时，先校准比例尺，再审核亮／暗轮廓和孔洞／裂隙排除区，保存全部更改后生成报告。

源码运行与 Windows 打包见 [BUILDING.md](../BUILDING.md)。本项目采用 [AGPL-3.0-only](../LICENSE)；第三方组件与对应源码信息见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 和 [SOURCE.md](../SOURCE.md)。
